# BMI Calculator

A simple **React Native** & **Expo** app to calculate BMI, show the category, and keep a history.

## Features
- Metric units (kg/cm)
- BMI categories: Underweight 🥗, Normal 💪, Overweight 🏃‍♂️, Obese ⚠️
- Color-coded results
- Light & Dark Mode
- History of previous BMI calculations

## Run
```bash
git clone https://github.com/PenarKera/BMI-Calculator.git
cd BMI-Calculator
npm install
npx expo start
